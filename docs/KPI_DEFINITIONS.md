\# KPI Definitions



\## Click-through rate



Formula:



`SUM(clicks) / SUM(impressions) × 100`



Meaning:



The percentage of advertisement impressions that produced a click.



\## Click-to-visit rate



Formula:



`SUM(website\_visits) / SUM(clicks) × 100`



Meaning:



The percentage of clicks that became website visits.



\## Conversion rate



Formula:



`SUM(orders) / SUM(website\_visits) × 100`



Meaning:



The percentage of website visits that produced an order.



The denominator is website visits, not impressions or clicks.



\## Return on ad spend



Formula:



`SUM(revenue) / SUM(ad\_spend)`



Meaning:



The revenue generated for every PKR 1 spent on advertising.



ROAS measures revenue, not profit.



\## Average order value



Formula:



`SUM(revenue) / SUM(orders)`



Meaning:



The average revenue generated by one order. One order may contain multiple units.



\## Cost per order



Formula:



`SUM(ad\_spend) / SUM(orders)`



Meaning:



The average advertising cost required to generate one order.



\## Division-by-zero rule



SQL calculations use `NULLIF(denominator, 0)`.



If the denominator is zero, the KPI returns `NULL` instead of causing an error.
